# vcf-sv-stats 1.1.0

This release updates the distribution and performance qualification contract.
The release artifact set is exactly one universal `py3-none-any` wheel and a
`SHA256SUMS` file for that wheel. Benchmark qualification passed: candidate
threads=1 improved median elapsed time by 25.030870% versus released 1.0.1,
and candidate threads=8 was 0.026662% slower than candidate threads=1.

Runtime changes are narrowly scoped to HTSlib/BGZF input thread propagation,
sparse relationship-only EventStore rows with deferred indexes, and single
record rendering with raw-field reuse. `--threads` enables HTSlib/BGZF
compressed-input decompression concurrency. Python semantic scanning and
cross-record relationship resolution remain serial.
