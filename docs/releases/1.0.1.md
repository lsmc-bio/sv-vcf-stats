# vcf-sv-stats 1.0.1

`1.0.1` makes the qualified v1 implementation directly installable from a
public GitHub release. It does not change runtime APIs, CLI behavior, schemas,
statistics, adapters, fixtures, or MultiQC integration.

## Install

Use the wheel attached to this release in Python 3.11, 3.12, or 3.13:

```bash
python -m pip install --no-cache-dir \
  "https://github.com/lsmc-bio/sv-vcf-stats/releases/download/1.0.1/vcf_sv_stats-1.0.1-py3-none-any.whl"
vcf-sv-stats version
vcf-sv-stats-verify-install
```

For Conda, use pip inside the environment with the same URL:

```bash
conda create --yes --name vcf-sv-stats python=3.13 pip
conda run --name vcf-sv-stats python -m pip install --no-cache-dir \
  "https://github.com/lsmc-bio/sv-vcf-stats/releases/download/1.0.1/vcf_sv_stats-1.0.1-py3-none-any.whl"
conda run --name vcf-sv-stats vcf-sv-stats version
conda run --name vcf-sv-stats vcf-sv-stats-verify-install
```

This is a pip installation inside Conda, not a native Conda package or channel.

## Release assets and boundaries

- The uploaded wheel is built and verified by the existing distribution
  workflow running on the exact annotated `1.0.1` tag.
- `SHA256SUMS` binds the uploaded wheel bytes.
- GitHub's automatically generated source snapshots are not the supported
  installation artifact for this release.
- Nothing is uploaded to PyPI, Bioconda, a Conda channel, a container registry,
  or the Sigstore transparency log.

notes and repository ledgers. The independent completion-review backlog remains
