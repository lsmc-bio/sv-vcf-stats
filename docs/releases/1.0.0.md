# vcf-sv-stats 1.0.0

`1.0.0` is the first complete implementation of the stable v1 contract for
standards-aware structural-variant and copy-number VCF/BCF inspection,
validation, descriptive statistics, discrepancies, and conservative
normalization.

This GitHub release is retained in a private repository. It does not change
repository visibility and does not publish a package, Conda artifact, or
container image to a registry.

## Highlights

- Streaming canonical observations keep source records, alternate alleles,
  breakends, resolved events, genotype calls, VCF sample columns, analysis
  units, and callsets as distinct statistical grains.
- Evidence-ranked adapters cover Manta, TIDDIT, dysgu, Sniffles2, LongReadSV,
  CNVscope, Jasmine, and SURVIVOR, with explicit provisional and unsupported
  states for unproven dialects.
- Finalized VCF 4.5 canonical normalization supports lossless multiallelic
  splitting across `Number=A/R/G/P/LA/LR/LG`, arbitrary supported ploidy,
  genotype and phase state, local alleles, IDs, mates, events, and complete
  source lineage.
- Source-versus-merged comparison reports `preserved`, `not_preserved`,
  `not_found`, and `ambiguous` without proposing evidence for reinsertion.
- Atomic VCF.gz/BCF publication binds the request, data, index, transformation
  manifest, and receipt through a one-way digest graph.
- Deterministic summary JSON carries schemas, content signatures, metric
  contracts, and an RFC 8785 payload digest for downstream consumers.
- A maintained MultiQC fork consumes only the compact summary artifact and
  preserves report, analysis-unit, and VCF-sample identity boundaries.

## Evidence

- Python 3.11, 3.12, and 3.13 tests and installed-distribution verification.
- Independent HTSlib/bcftools 1.24 validation.
- Twenty-four offline wheel and source-archive installation receipts across
  Linux and macOS, x86_64 and arm64, and all supported Python versions.
- Multi-architecture OCI audit, SPDX and CycloneDX SBOMs, SLSA v1 provenance,
  Conda recipe build, and Apptainer read-only/non-root smoke evidence.
- Deterministic 100K through 10M record performance, memory, temporary-space,
  thread-invariance, and interruption-recovery qualification.
- Twenty-one heavily subsampled source-derived HG002 fixtures plus BCF and plain
  VCF parity artifacts, all with a dated per-artifact redistribution review.
- Zero findings from the hashed `BRAND-002` and structural neutrality policies
  across the qualified source, history, built artifacts, and workflow evidence.

## Supported boundary

- Inputs are local VCF, VCF.gz, BCF, or standard input. There is no telemetry or
  remote-input discovery.
- The only network-capable runtime operation is explicit, confirmed retrieval
  of a pinned public reference profile.
- `conservative` and proven `canonical` rewrites are implemented.
  `caller-lossless` remains reserved and unsupported; lossy authorization is
  rejected.
- Statistics are descriptive callset properties, not truth concordance,
  precision, recall, clinical validity, or pathogenicity.
